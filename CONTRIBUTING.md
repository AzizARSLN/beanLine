# Contributing

## Reporting a bug

Open an issue with your IDE version, the framework you use and a small code sample that shows the problem. For a
wrong inspection warning, include the code it was reported on.

## Making a change

1. Install JDK 21 and fork the repository.
2. Run `./gradlew runIde` to try the plugin in a sandbox IDE.
3. Add a test for your change and run `./gradlew test`.
4. Open a pull request that describes the change.
